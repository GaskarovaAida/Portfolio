Яндекс Книги: анализ LTV и активности пользователей

Автор: Гаскарова А.А. · SQL · Python · pandas · SciPy · Matplotlib · Seaborn

Проект включает две самостоятельные аналитические задачи: расчёт LTV по Москве и Санкт-Петербургу и проверку заданной условиями проекта гипотезы о времени активности пользователей.

Важно: направление статистической гипотезы задано условием проекта изначально и не выводится из результатов расчёта LTV. Эти два этапа анализируют разные характеристики пользовательского поведения.

1. Расчёт LTV

В рамках задания пользователь приносит 399 ₽ за каждый месяц, в котором хотя бы один раз пользовался Яндекс Книгами. Средний LTV рассчитывается как общий доход, делённый на число уникальных пользователей.

Средний LTV в Москве выше на 32,73 ₽, или примерно на 4,5% относительно Санкт-Петербурга.

SQL расчёта LTV
WITH user_months AS (
    SELECT DISTINCT
        a.puid,
        g.usage_geo_id_name AS city,
        DATE_TRUNC('month', CAST(a.msk_business_dt_str AS DATE)) AS month
    FROM bookmate.audition AS a
    JOIN bookmate.geo AS g
        ON a.usage_geo_id = g.usage_geo_id
    WHERE g.usage_geo_id_name IN ('Москва', 'Санкт-Петербург')
),
city_metrics AS (
    SELECT
        city,
        COUNT(DISTINCT puid) AS total_users,
        COUNT(*) * 399 AS total_revenue
    FROM user_months
    GROUP BY city
)
SELECT
    city,
    total_users,
    ROUND(total_revenue * 1.0 / total_users, 2) AS ltv
FROM city_metrics
ORDER BY city;

4. Проверка гипотезы

Условиями проекта заранее задана направленная гипотеза:

  • H₀: среднее время активности пользователей Санкт-Петербурга не больше, чем в Москве.
  • H₁: среднее время активности пользователей Санкт-Петербурга больше, чем в Москве.

Использован односторонний t-тест Уэлча для двух независимых выборок при уровне значимости α = 0,05.

5. Итоговая аналитическая записка

Основные результаты

Средний LTV выше в Москве — 764,55 ₽ против 731,82 ₽. Отдельно проверенная, заранее заданная условиями проекта гипотеза о более высоком среднем времени активности пользователей Санкт-Петербурга статистически не подтвердилась: p-value = 0,3318 > 0,05.

Интерпретация

Результаты двух частей проекта не противоречат друг другу, потому что метрики отражают разные характеристики поведения. В используемой модели LTV определяется числом активных месяцев, а hours — интенсивностью чтения и прослушивания. Причинную связь между LTV и количеством часов этот анализ не устанавливает.

Рекомендации

  • Для дальнейшего анализа LTV рассмотреть число активных месяцев, retention, churn и динамику возвращаемости пользователей.
  • Для анализа интенсивности использования дополнительно сравнить медианы, квантили, долю высокоактивных пользователей и отдельные пользовательские сегменты.
  • При наличии данных отдельно изучить чтение и прослушивание.
